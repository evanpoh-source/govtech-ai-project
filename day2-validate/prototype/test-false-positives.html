False Positive Test

Does the checker catch bad inputs, or does it let them through as "OK" to the officer?

What this tests: 12 deliberately bad submissions are run through the checker. Each has at least one known error. The test checks whether the officer summary report correctly flags every bad field. If any known-bad field shows as "OK" in the officer report, that is a false positive and the kill switch fires.
